# BunnyEra Browser

BunnyEra Browser integrates desktop utilities, automation tools, and cross‑border workflows into the BunnyEra ecosystem.  
It acts as a bridge between local tools, cloud services, and AI‑powered automation.

## Features
- Browser automation utilities
- Cross‑border workflow helpers
- Desktop integrations
- Cloud sync and data routing
- Modular tool extensions

## Project Structure
- `/src` — Core browser integration logic
- `/tools` — Utility modules
- `/config` — Environment and settings
